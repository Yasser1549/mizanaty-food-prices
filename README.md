ميزانيتي – تحديث أسعار الغذاء

مشروع إنشاء خدمة مركزية لتحديث أسعار الأغذية في مصر وربطها بتطبيق ميزانيتي.

الهدف

- عرض أسعار الأغذية تلقائيًا دون إدخال يدوي.
- إعطاء الأولوية لأسعار الإسكندرية.
- استخدام متوسط الجمهورية عند عدم توفر سعر محلي موثوق.
- إظهار مصدر السعر وتاريخ آخر تحديث.
- الاحتفاظ بآخر سعر موثوق عند فشل التحديث.
- تحديث تكلفة الوصفات تلقائيًا عند تغير الأسعار.

مكونات المشروع

1. GitHub Actions لتشغيل التحديث الدوري.
2. مصادر أسعار موثوقة ومسموح باستخدامها.
3. Firebase Realtime Database لحفظ الأسعار.
4. تطبيق ميزانيتي لعرض الأسعار وحساب تكلفة الوجبات.

مراحل التنفيذ

- [ ] تجهيز قائمة الأصناف.
- [ ] بناء مهمة التحديث الآلي.
- [ ] ربط Firebase.
- [ ] ربط تطبيق ميزانيتي.

الأمان

لا تُحفظ كلمات المرور أو مفاتيح حسابات الخدمة داخل المستودع. تُستخدم GitHub Secrets عند الحاجة.

ملاحظة: لم يتم نشر أسعار فعلية أو تشغيل تحديث آلي حتى الآن.
